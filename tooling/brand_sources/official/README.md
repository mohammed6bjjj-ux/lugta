# Official Lugta logo sources

These are the five production masters selected from the supplied 12-export
logo pack. They match the primary composition and permitted single-colour
uses shown in `هوية بصرية لكطة فاينل.pdf`.

- `lugta_mark_primary.png` - source Asset 17; primary app and UI mark.
- `lugta_mark_monochrome.png` - source Asset 14; Android monochrome mask.
- `lugta_wordmark_primary.png` - source Asset 11; primary horizontal lockup.
- `lugta_wordmark_purple.png` - source Asset 10; single-colour light-surface lockup.
- `lugta_wordmark_white.png` - source Asset 7; reverse lockup for dark surfaces.

The remaining yellow, black, and inverse colour exports are intentionally not
bundled because current app, splash, icon, and store placements do not require
them. Generated runtime assets are produced by `tooling/generate_brand_assets.py`.
