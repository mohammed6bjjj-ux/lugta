# Lugta — لُگطة

تطبيق Flutter للبائعين مرتبط بمشروع Supabase الإنتاجي الخاص بمنصة لُگطة.

## الوظائف الحالية

- تسجيل الهاتف وOTP عبر WhatsApp، مع مراجعة حساب البائع.
- كتالوج متعدد اللغات بوسائط مخزنة في Supabase Storage.
- إنشاء الطلب مع سعر البيع، أجرة المحافظة، وعروض التوصيل المجاني.
- اختيار علبة مجانية أو مدفوعة للمنتجات المفعّل لها التعليب.
- متابعة الطلب والأرباح والسحوبات.
- تقديم شكوى أو بلاغ مرتبط بأي طلب ومتابعة رد الإدارة.
- تحديثات Realtime وكاش للصور والكتالوج لتحسين العمل على الإنترنت الضعيف.
